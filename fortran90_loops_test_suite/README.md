# Fortran90 Operator Test Suite

This folder tests the `loop_N` operators contained in the local `thermal_lines.f90` file.

## Basic use

Compile the test suite:

```bash
make
```

Run with defaults:

```bash
./operator_test_suite
```

This uses:

```text
configuration = ../fortran77_scalar_looptest/run1_52x26x26x26nc2rADJnf2b2.300000m1.000000n1
output file   = operator_outputs.dat
time slice    = 1
site          = (x,y,z) = (1,1,1)
loops         = all loop_N routines found in thermal_lines.f90
```

## Reference configuration

The current old-vs-new loop comparison was tested against this gauge configuration:

```text
../fortran77_scalar_looptest/run1_52x26x26x26nc2rADJnf2b2.300000m1.000000n1
```

This file should stay local and should not be committed to Git.

## Full command format

```bash
./operator_test_suite CONFIG OUTPUT N4 X Y Z FIRST_LOOP LAST_LOOP
```

Arguments:

```text
CONFIG      path to the gauge configuration
OUTPUT      output file to write
N4          time slice
X           x coordinate of the spatial site
Y           y coordinate of the spatial site
Z           z coordinate of the spatial site
FIRST_LOOP  first loop/operator number to test
LAST_LOOP   last loop/operator number to test
```

## Examples

Test all loops with defaults:

```bash
./operator_test_suite
```

Test loops 9 to 12 at time slice 1 and site (1,1,1):

```bash
./operator_test_suite ../fortran77_scalar_looptest/run1_52x26x26x26nc2rADJnf2b2.300000m1.000000n1 out_9_12.dat 1 1 1 1 9 12
```

Test only loop 25:

```bash
./operator_test_suite ../fortran77_scalar_looptest/run1_52x26x26x26nc2rADJnf2b2.300000m1.000000n1 loop_25.dat 1 1 1 1 25 25
```

Test loops 146 to 185 at time slice 2 and site (3,4,5):

```bash
./operator_test_suite ../fortran77_scalar_looptest/run1_52x26x26x26nc2rADJnf2b2.300000m1.000000n1 plaq_146_185.dat 2 3 4 5 146 185
```

## How loop selection works

The last two numbers select the loop range:

```text
FIRST_LOOP LAST_LOOP
```

For example:

```text
9 12
```

means: test loops 9, 10, 11, and 12.

```text
25 25
```

means: test only loop 25.

## How the dispatcher works

`generate_dispatch.py` scans `thermal_lines.f90` and finds every subroutine named:

```fortran
subroutine loop_N(...)
```

Then it creates `operator_dispatch.f90`, which contains the `select case` block that calls the correct loop.

You should not edit `operator_dispatch.f90` by hand. It is regenerated by `make`.

If you replace `thermal_lines.f90`, run:

```bash
make clean
make
```
